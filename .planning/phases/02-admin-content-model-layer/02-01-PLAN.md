<threat_model>

## Scope

This plan adds admin-managed database models and Django Admin configuration for global company content, social links, statistics, banners, and known website pages.

## Trust Boundaries

- Authenticated Django staff users can create and edit records through Django Admin.
- Uploaded media metadata enters the database through admin forms.
- Public users do not interact with these models directly in Phase 2.

## STRIDE Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01 | Tampering | Admin-managed global/site data | Medium | Mitigate | Use Django Admin authentication/permissions, explicit fields, and validation for singleton/company/page records. |
| T-02 | Information Disclosure | Media/file fields | Medium | Mitigate | Store only file paths via Django fields; do not add public media APIs or unrestricted upload endpoints in this phase. |
| T-03 | Spoofing | Social links and contact details | Low | Mitigate | Keep edits restricted to staff admin; add admin search/list displays so changes are visible and reviewable. |
| T-04 | Denial of Service | Duplicate singleton profiles | Low | Mitigate | Enforce one `CompanyProfile` row through model/admin safeguards and tests. |

</threat_model>
