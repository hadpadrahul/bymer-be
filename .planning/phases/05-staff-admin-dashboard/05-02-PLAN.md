# Plan 05-02: Globals, pages, catalog, content CRUD

## Objective

Full template-based CRUD for global settings, pages, catalog, and all repeatable content collections; registry for extensibility; copy API helpers on detail screens.

## Tasks

### T1 — Content registry
- `dashboard/registry.py`: register each model with list URL, form URL, public API path template, icon label
- Template tag `{% copy_api_url %}`

### T2 — Globals
- Company profile singleton form
- Social links, statistics, banners: list + create/edit/delete(deactivate)
- Banner form includes page FK, CTA fields, image, video, order, active

### T3 — Pages
- Page list (known slugs); create/edit slug/meta/order/active — restrict slug choices to allowed set from compose map
- Page detail: read-only sections table from `build_page_sections` + links to collections

### T4 — Catalog
- Categories CRUD with delete protection if products exist
- Products, machinery: list/filter/search/paginate + forms with image upload

### T5 — Content collections
- Team, timelines, clients, testimonials, certifications, awards, FAQs
- Shared list/form partials where possible
- File fields: image/PDF validation

### T6 — AJAX endpoints (`/api/admin/`)
- PATCH `is_active` toggle
- PATCH `order` update
- Optional: banner image upload preview partial

### T7 — Tests
- Client tests per major list/create/update
- API tests for toggle/reorder

## Verification

- Editor can CRUD each entity without Django Admin
- Copy buttons show correct `/api/...` paths
- Category with products cannot delete
