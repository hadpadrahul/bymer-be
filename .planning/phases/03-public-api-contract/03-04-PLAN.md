<threat_model>

## Scope

Public write endpoints for contact and career submissions.

## Trust Boundaries

- Anonymous visitors may POST form data.
- Stored submissions must not be readable via public API.

## STRIDE Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01 | Information Disclosure | Stored PII via GET | High | Mitigate | Create-only views; tests assert GET returns 405/404. |
| T-02 | Tampering | Invalid submissions | Medium | Mitigate | Serializer validation; return 400 with field errors. |
| T-03 | Denial of Service | Form spam | Medium | Defer | Document rate limiting as v2; validate required fields now. |

</threat_model>
